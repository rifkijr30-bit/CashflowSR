# Cash Flow Pribadi

Pencatat keuangan pribadi yang bisa diinstal di HP (PWA). Data tersimpan di Google Sheet milik sendiri melalui Apps Script.

- `index.html` — aplikasi
- `manifest.json`, `sw.js`, `icon-*.png` — supaya bisa diinstal di HP

Backend (`Code.gs`) dipasang di Google Sheet, **tidak** diunggah ke repo ini. Jangan pernah menaruh TOKEN asli di repo.
